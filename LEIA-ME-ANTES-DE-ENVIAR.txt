COMO ENVIAR AO GITHUB

Não apague as pastas css e js que já existem no repositório.

1. Extraia este ZIP.
2. Entre na pasta extraída.
3. Envie o CONTEÚDO da pasta para a raiz do repositório.
4. Substitua os HTMLs e as imagens quando o GitHub perguntar.
5. Faça o commit na branch usada pelo GitHub Pages.
6. Aguarde a publicação.
7. Recarregue a página com Ctrl + F5.

A página deve continuar neste endereço:
